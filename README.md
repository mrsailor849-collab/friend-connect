# Camera & Location Demo

This project demonstrates:

- Browser Location Permission
- Browser Camera Permission

## Files

- index.html
- style.css
- script.js

## Run

Upload all files to:

- GitHub Pages
- Netlify
- Vercel
- Replit

or run locally.

## Important

The browser will ask the user for permission.

Camera and location access work only when:

1. Website is served over HTTPS.
2. User clicks Allow.
3. Browser supports the APIs.
